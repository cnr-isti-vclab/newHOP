# Decision 0017: Support unnamed GLB animation clips

## Status

Accepted

## Context

GLB/GLTF files may contain animation clips without a glTF `name`. Requiring a
source name for autoplay makes those clips unusable even though Three.js can
load and play them. The animation example also needs to work with assets whose
clip names are not known in advance.

## Decision

Animation discovery exposes a stable display name for unnamed clips:
`Animation 1`, `Animation 2`, and so on. The scene-level `animation.clip`
property is optional. When autoplay is enabled without a clip name, the first
loaded clip is played.

Explicit clip names remain supported. Runtime callers can use
`getObjectAnimations()` to discover the available names before calling
`playObjectAnimation()` or `setObjectAnimationTime()`.

## Consequences

- Assets do not need to be renamed before they can be played.
- Existing scenes that specify a clip name retain their behavior.
- Display names are generated by clip order and are intended for the current
  loaded asset, not as persistent identifiers across asset revisions.
