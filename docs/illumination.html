Lighting

The lighting block creates lights for the scene and an optional camera-mounted flashlight. The lights subblock defines all the lights that will be present in the scene. Each light is identified by its unique key, which serves as the runtime identifier for that light, and a set of parameters (different for each light type). The flashlight subblock defines the optional camera-mounted flashlight.

Lights on/off status can also be defined at the declaration stage.

Lighting block example


lighting: {
  lights: {
    fill: {
      type: 'hemisphere',
      color: 0xffffff,
      groundColor: 0x444444,
      intensity: 1,
      position: [0, 1, 0]
    },
    key: {
      type: 'directional',
      color: 0xfff1d6,
      intensity: 1.5,
      position: [2, 3, 4],
      target: [0, 0, 0]
    }
  },
  flashlight: {
    color: 0xaabbbb,
    enabled: false
  }
}

Default lights

If lighting is omitted, or if lighting.lights is an empty collection, newHOP creates two named scene lights automatically. Their names are used by the runtime lighting APIs.

NameTypeDefault properties
default-hemisphereHemisphereSky color 0xffffff, ground color 0x444444, intensity 1.2, position [0, 1, 0]
default-keyDirectionalColor 0xffffff, intensity 1.5, position [2, 3, 4], target [0, 0, 0]

As soon as you provide one or more entries in lighting.lights, those entries replace the default collection. Include every scene light you want to keep. Specifying only lighting.flashlight does not replace the defaults; the flashlight is managed separately.


lighting: {
  lights: {
    // The default lights are replaced; declare all desired scene lights here.
    key: { type: 'directional', position: [500, 900, 700], intensity: 2 }
  },
  flashlight: { enabled: true }
}

Lights management at runtime

At runtime, presenter.getSceneLightsIDs() returns a list of all lights of the scene. Flashlight is not in this list, as is managed separately.


const sceneLights = presenter.lighting.getSceneLights();
console.log(sceneLights);

At runtime, existing lights can be removed from the scene or new lights can be added.


// removing a specific light from the scene
presenter.lighting.removeSceneLight('Sun');

// adding a new light to the scene
presenter.lighting.addSceneLight('newSun', {
  type: 'directional',
  color: 0xffffff,
  intensity: 1,
  position: [1, 2, 3]
});

At runtime, it is possible to query the status of each light (The structure is a copy; changing that local object does not change the scene). It is also possible to update a specific light's parameters using the same structure used in its creation. And a shorthand method exists to change only the on/off state of a specific light.


// querying the state of a specific light
const fillLight = presenter.lighting.getSceneLight('fill');
console.log(fillLight);

// updating a specific light at runtime
presenter.lighting.setSceneLight('fill', {
  type: 'hemisphere',
  enabled: true,
  intensity: 3.14,
  color: 0xff00ff,
  groundColor: 0x333333,
  position: [0, 1, 0]
});

// changing only the on/off state of a specific light
presenter.lighting.setSceneLightEnabled('fill', false);

Basic light types

ambient

Applies uniform illumination without direction. It has no useful position, target, rotation, or distance. Ambient and hemisphere lights are mutually exclusive in one scene-light collection.

lights: {
  ambientFill: {
    type: 'ambient',
    enabled: true,
    color: 0xffffff,
    intensity: 0.65
  }
}
ParameterMeaningDefault
typeMust be 'ambient'.Required
enabledWhether the light contributes illumination.true
colorUniform light color as a hexadecimal number.0xffffff
intensityUniform light intensity.1

WARNING: there should only be only one ambient OR one hemisphere light in a scene-light collection.

hemisphere

Uses two colors: color for the sky-facing direction and groundColor for the opposite direction. Surface normals between those directions receive a blend. The light position determines the sky direction.


lights: {
  skyFill: {
    type: 'hemisphere',
    enabled: true,
    color: 0x8899cc,
    groundColor: 0x443b32,
    intensity: 1.2,
    position: [0, 1, 0]
  }
}
ParameterMeaningDefault
typeMust be 'hemisphere'.Required
enabledWhether the light contributes illumination.true
colorSky-facing color.0xffffff
groundColorGround-facing color.0x444444
intensityHemisphere light intensity.1
positionDirection toward the sky color.[0, 1, 0]

WARNING: a hemisphere light needs a meaningful position. Its position establishes the sky direction. For the default Y-up convention, [0, 1, 0] points the sky upward. For a Z-up scene, use a position such as [0, 0, 1] when that matches the authored world. This direction is authored explicitly; it is not inferred from navigation.

WARNING: there should only be only one ambient OR one hemisphere light in a scene-light collection.

directional

Provides parallel light rays. Use position and target to define the direction. The target is a world-space point and is useful for aiming the light at a building or scene center.


lights: {
  sun: {
    type: 'directional',
    enabled: true,
    color: 0xfff1d6,
    intensity: 2,
    position: [500, 900, 700],
    target: [0, 100, 0],
    rotation: [0, 0, 0],
    castShadow: true
  }
}
ParameterMeaningDefault
typeMust be 'directional'.Required
enabledWhether the light contributes illumination.true
colorParallel ray color.0xffffff
intensityDirectional light intensity.1
positionLight source position used with the target.[0, 0, 0]
targetWorld-space point toward which the light points.Three.js target origin
rotationEuler rotation in X, Y, Z order, in degrees.[0, 0, 0]
castShadowEnables directional shadow casting.false

Advanced light types

WARNING: These light types provide more control over illumination and are suitable for specific effects in a scene, but they may require more careful setup and tuning of parameters that heavily depends on the scene scale, size and material properties.

point

Emits light from a point in all directions. Its falloff is controlled by distance and decay, so large scenes may require appropriately scaled intensity and range.


  lights: {
  lamp: {
    type: 'point',
    enabled: true,
    color: 0x7dd3fc,
    intensity: 250000,
    position: [-500, 450, 350],
    distance: 1800,
    decay: 2,
    castShadow: true
  }
}
ParameterMeaningDefault
typeMust be 'point'.Required
enabledWhether the light contributes illumination.true
colorPoint-light color.0xffffff
intensityPoint-light intensity.1
positionPoint-light source position.[0, 0, 0]
distanceMaximum range; zero means unlimited in Three.js.10
decayLight falloff factor.2
rotationAccepted for the scene definition but has no visual effect on an omnidirectional point light.[0, 0, 0]
castShadowEnables point-light shadow casting.false

spot

Emits a cone of light from a position toward a target.


lights: {
  accent: {
    type: 'spot',
    enabled: true,
    color: 0x558855,
    intensity: 120000,
    position: [250, 700, -500],
    target: [0, 100, 0],
    distance: 1800,
    angle: 32,
    penumbra: 0.45,
    decay: 1.5,
    castShadow: true
  }
}
ParameterMeaningDefault
typeMust be 'spot'.Required
enabledWhether the light contributes illumination.true
colorSpotlight color.0xffffff
intensitySpotlight intensity.1
positionSpot source position.[0, 0, 0]
targetWorld-space point at the center of the cone.Three.js target origin
distanceMaximum cone range.10
angleMaximum cone angle.30 degrees
penumbraEdge softness from zero to one.0.5
decayLight falloff factor.2
rotationEuler rotation in X, Y, Z order, in degrees.[0, 0, 0]
castShadowEnables spotlight shadow casting.false

Flashlight

The flashlight is a camera-mounted Three.js directional light. It follows the camera, keeps a constant intensity across distance, and can be changed through the public lighting manager. Its orientation is expressed in camera-local coordinates, so zero orientation always follows the camera's current view in both Y-up and Z-up scenes.


lighting: {
  flashlight: {
    enabled: true,
    color: 0xffb36b,
    intensity: 1,
    azimuth: 0,
    elevation: 0
  }
}
ParameterMeaningDefault
enabledWhether the flashlight contributes light.false
colorFlashlight color.0xffffff
intensityFlashlight intensity.1
azimuthHorizontal direction angle in degrees within the camera view. Zero points along the camera's current forward direction.0
elevationAngle in degrees above or below the camera's current forward direction.0
presenter.lighting.setFlashlight({
  enabled: true,
  color: 0xffb36b,
  intensity: 3,
  azimuth: 0,
  elevation: 0
});

presenter.lighting.toggleFlashlight();

Enable flashlight aiming to temporarily give the left mouse drag to the light instead of navigation. The light remains camera-mounted, and its orientation is limited to the configured angle range. Dragging changes the camera-relative azimuth and elevation; the same control behavior applies in Y-up and Z-up scenes:

presenter.setFlashlightMode(true);
// left-button drag changes azimuth and elevation
presenter.setFlashlightMode(false);

const orientation = presenter.lighting.getFlashlightOrientation();
presenter.lighting.setFlashlightOrientation(20, -10);

Runtime scene-light controls

Set enabled: false in any scene-light definition to start that light disabled. The default is true. Named lights use the key from lighting.lights. Runtime setters use the same definition shape as scene creation:

presenter.lighting.setSceneLightEnabled('key', false);
const enabled = presenter.lighting.isSceneLightEnabled('key');
const ids = presenter.getSceneLightIds();

const keyLight = presenter.lighting.getSceneLight('key');
presenter.lighting.setSceneLight('key', {
  type: 'directional',
  enabled: true,
  color: 0xfff1d6,
  intensity: 2.5,
  position: [500, 900, 700],
  target: [0, 100, 0],
  castShadow: true
});

const flashlight = presenter.lighting.getFlashlight();
presenter.lighting.setFlashlight({ ...flashlight, enabled: true });

Scene lights also have explicit creation and destruction methods:

presenter.lighting.addSceneLight('rim', {
  type: 'point',
  color: 0x7dd3fc,
  intensity: 250000,
  position: [-500, 450, 350],
  distance: 1800,
  decay: 2
});
presenter.lighting.removeSceneLight('rim');
