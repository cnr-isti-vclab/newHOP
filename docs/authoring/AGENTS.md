# Authoring documentation guidance

This folder contains documentation intended for authors who use the built
newHOP library to create visualization webpages.

## Open work

- Write the complete author-facing README.
- Complete `distribution-index.html`, which the package builder will publish
  as the distribution-root `index.html`.
- Document installation, local serving, and offline deployment.
- Keep the documentation aligned with the curated examples and the generated
  distribution package.
- Avoid developer-only implementation details, internal workflows, and
  repository maintenance instructions.
