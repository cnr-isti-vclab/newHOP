newHOP documentation

Reference pages for scene authoring, runtime control, and the TypeScript library. The documentation is plain HTML so it can be served, published, or copied with the rest of a project.

Objects

Load models and define supplied geometry, transforms, material sidecars, visual settings, tags, and runtime entity control.

World

Configure the scene background, camera projection, and authored-content alignment through the world block.

Spots

Author primitive or custom hotspots, configure transforms and highlighting, and control them at runtime.

Navigation and Trackball

Configure turntable navigation, initial views, limits, panning, animation, input locking, and runtime status.

Interaction

Understand navigation input, generic object picking, spot clicks, measurement, clipping, and tool ownership.

Basic Toolbar

Assemble the optional built-in toolbar from predefined controls, layout items, and custom button declarations.

Illumination

Configure illumination, declaring light sources and runtime toggles.
