World

The world block defines the scene background, camera projection, and transforms applied to all authored content. Camera movement and interaction settings belong to the separate navigation block.

Background

Set a solid background with a hexadecimal color number or an object containing color. An image background uses an equirectangular image; its URL is resolved relative to the document URL.

world: {
  background: 0x202b3c
}

// Or use an equirectangular image
world: {
  background: {
    file: 'media/environment.jpg',
    azimuth: -90
  }
}

The image azimuth is in degrees. Its vertical orientation follows navigation.upAxis. A background image is displayed as the scene background; environment lighting is configured separately through the lighting block.

Camera Projection

Perspective is the default projection. Select orthographic projection through world.camera.type. Projection belongs to the world camera, while movement and orbit behavior belong to navigation.

world: {
  camera: {
    type: 'perspective',
    fov: 42,
    near: 0.01,
    far: 1000
  }
}
PropertyMeaningDefault
type'perspective' or 'orthographic'.'perspective'
fovPerspective vertical field of view in degrees. It also provides the scale reference when matching the two projections.45

Switch projection or update these values at runtime through the Presenter. Switching preserves the navigation target and viewing direction while matching the apparent scale at the current target plane.

presenter.setCameraType('orthographic');
presenter.setCameraProjection({ fov: 55, near: 0.1, far: 5000 });
const projection = presenter.getCameraProjection();

Content alignment

Use world.sceneTransform to align all authored content without rotating the camera, base grid, axes, or explicit world-space section planes. This transform is applied above each object's local transform and is included in scene bounds, picking, and measurements.

world: {
  sceneTransform: {
    rotation: [0, 0, 20]
  }
}

Component transforms use degrees and may specify position, rotation, or scale. A column-major 4x4 matrix can be used instead; when present, it overrides the component fields.

Update or inspect the transform at runtime with presenter.setSceneTransform(update) and presenter.getSceneTransform().
