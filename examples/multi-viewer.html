Two viewers, one page

A minimal embedded-viewer layout. Each Presenter owns its own scene, camera, navigation, renderer, and toolbar.

Viewer 1 · perspective
Viewer one

Laurana in perspective

This viewer uses the default perspective camera, a warm background, and a restrained lighting setup. Its toolbar controls only this canvas.

Viewer two

Gargoyle in orthographic

This viewer uses an orthographic camera and a cool background. It is independent from the Laurana viewer: orbiting, zooming, fitting, or switching tools does not affect the other scene.

Viewer 2 · orthographic

Both viewers use the same newHOP distribution and can be embedded alongside ordinary page content.
